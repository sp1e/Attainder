# Public inventory derivative

Codex prepared 1,011 inventory records in the `attainder-public-inventory-v1` format. Each record contains the eight fields required by the Phase 6 contract. The candidate awaits independent data and privacy review before publication.

## Research status and start references

Codex retained 400 records as `no-source`, with their source URL and start references set to `null`. That status records the current research withholding decision. Of the other records, 601 remain `pending`, seven retain a scoped `playable-candidate` assessment and three retain a scoped `map-only` assessment.

The ten assessed records reference existing polities at their reviewed dates. The current game classifies seven of these records as playable and three as on-map. Two records refer to Western Xia under distinct regional inventory identities. Counts therefore describe inventory records; they do not count distinct historical societies or establish a coverage percentage. This derivative adds no playable polity.

Another 139 pending records reference identically labelled features whose current boundary decision is `withheld-control`. Codex checked their source indexes and labels against the shipped packages and pinned map files. These references provide research leads. They establish neither historical identity across periods nor control at the start date. The game retains their pending status and labels the map areas as unknown historical control.

Codex left 862 records without a start reference. Six of these have unresolved mapping choices: one label matches two features at the earliest start, and five records match accepted or owned features without the required reviewed identity binding. Codex retained those choices for later research instead of assigning an arbitrary feature or a different historical period.

## Field selection

Codex carried forward 454 existing public HTTPS source references without changing their addresses. The remaining 557 records have `sourceUrl: null`: 400 follow the withholding decision, and 157 have references outside the contract's HTTPS format. Codex performed no new historical-source assessment for this projection. A retained URL identifies an earlier research reference; it supplies no new whole-record approval.

The regional labels are editorial report groups. Assigning one region to each record simplifies cultures and movements that cross those groups. The identifier prefix retains the original inventory grouping, so it can differ from `regionId`.

Codex issued permanent identifiers from the original regional namespace and a normalized name label, then checked uniqueness across all 1,011 records. Future editors must preserve these issued identifiers through renames, consolidations and reordered source arrays. The private correspondence register supports those edits and stays outside the public export.

Run the existing start-coverage generator and commit its regenerated report with the inventory. Package coverage and gameplay still follow the shipped package data.
