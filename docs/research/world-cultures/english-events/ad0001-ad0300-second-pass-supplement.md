# Aqua Claudia research supplement

This second pass through 1–300 CE selects one episode: the construction of Aqua Claudia in 38–52 CE. Two public heritage sources support five displayed English fields and one selection note. The dataset is English research awaiting compatible runtime support.

Turismo Roma attributes the works to Caligula and Claudius. The regional park leaflet gives Aqua Claudia the same interval in both its description and construction table. This record concerns the building project and does not establish an inauguration day, uninterrupted work throughout the interval, an invention priority or a quantified increase in the city's water supply.

The leaflet's companion Anio Novus has inconsistent start dates: the joint paragraph begins both works in 38, whereas the table gives Anio Novus 47–52 CE. The source metadata preserves that difference. No Anio Novus construction event is adopted, and its chronology is not silently harmonized with Aqua Claudia's.
