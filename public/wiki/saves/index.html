    Sparfiler och säkerhetskopiorSaves and backups

    Spel, scenarier och kopior

    Ett scenario ger startvärlden och kartan. Ett spel är en kampanj som har skapats från scenariot. Använd menyn på spelkortet för att redigera, klona eller exportera en kampanj. En klon ger dig en separat gren att behålla innan du provar ett riskfyllt beslut. Scenariokort har en egen kloningsfunktion.

    Arkivering döljer ett spel från den vanliga bibliotekshyllan. Avarkivering tar fram det igen. Radering tar bort den lagrade posten. Exportera först om du kan vilja återvända till den.

    Games, scenarios and copies

    A scenario supplies the starting world and map; a game is a campaign made from it. Use the library’s game-card menu to edit, clone or export a campaign. A clone gives you a separate branch to keep before trying a risky decision. Scenario cards have their own clone action.

    Archiving hides a game from the ordinary library shelf; unarchiving brings it back. Deleting removes its stored record. Export first if you may want it again.

    Flytta och säkerhetskopiera en kampanj

    Välj Exportera på ett spelkort för att skapa dess ZIP-fil. Den innehåller kampanjpaketet och tillgängliga återställningspunkter samt en inställningsrapport när den kan skapas. Bibliotekets spelimport läser ZIP-filen och återställer en kampanj. Behåll filen utanför programmets lagring.

    En export kan innehålla privata kampanjsamtal, rådgivarutbyten och händelser. Granska den innan du publicerar den. På Android används hämtningarnas mapp eller delning som reserv. Läs om mobilen.

    Move and back up a campaign

    Choose Export on a game card to build its ZIP file. It includes the campaign bundle and available rollback snapshots, plus a settings report when available. The library’s game import reads that ZIP and restores a campaign. Keep the file outside the application’s storage.

    An export can contain private campaign conversations, advisor exchanges and events. Read it before posting it publicly. On Android, file saving uses the Downloads folder or a share fallback; see mobile.

    När kartan inte följer med

    Exporten försöker ta med varje tillgänglig matchande karta, även en inbyggd karta eller gemenskapskarta. Ett scenario som är större än 32 MiB lämnas utanför innan det hämtas till ZIP-filen. Saknade eller ogiltiga kartdata redovisas också. Skicka det matchande scenariot separat när exporten meddelar att kartan utelämnades.

    Importen behåller kampanjens personer och återspelningsdata även om kartan inte kan kopplas. Samma scenarioidentifierare räcker inte. Geografin måste stämma med kampanjen. Återställ det matchande scenariot innan du försöker spela på kartan. Scenariopaket kan exporteras som ZIP eller JSON från redigeringspanelen.

    When the map does not travel

    The exporter tries to carry every available matching map, including a built-in or community map. A scenario larger than 32 MiB is left out before fetching it for the ZIP. Missing or invalid map data is also reported. Send the matching scenario separately when the export says the map was omitted.

    Import preserves the campaign’s people and replay data even if its map is unresolved. A scenario with the same identifier is insufficient: its geography must match the campaign. Restore that matching scenario before trying to play on the map. Scenario bundles can be exported as ZIP or JSON from their editor drawer.

    Lagring och ångring

    Den lokala starten använder play-data under vald datarot. En annan datarot kan därför visa ett annat bibliotek. En fristående server använder OH_DATA_DIR när den har angetts. Ren webbläsarlagring behåller spelposterna i webbläsaren. Rensning av webbplatsens lagring kan ta bort dessa poster. Beständig lagring begärs där webbläsaren stöder det, men en extern säkerhetskopia är fortfarande användbar.

    Tidslinjens ångring använder tillgängliga ögonblicksbilder från före turen. Arkivet har en gräns på 12, och sparandet av en ögonblicksbild kan misslyckas. Kontrollera hur många ångringar som finns. En ögonblicksbild ersätter inte en exporterad säkerhetskopia. Läs om tid för kampanjens tidsreglage.

    Storage and undo

    The local launcher uses play-data under its selected data home. Changing the data home can therefore show a different library. A standalone server uses OH_DATA_DIR when set; browser-only storage keeps game records in the browser. Clearing that site’s storage can remove those records. Persistence permission is requested where the browser supports it, but an external backup remains useful.

    The timeline’s undo uses available pre-turn snapshots. The snapshot archive is capped at 12, and capture is best-effort. Check the available undo count; a snapshot is not a substitute for an exported backup. Read time for the campaign’s turn controls.
