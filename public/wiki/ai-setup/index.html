    Anslut en modellConnect a model

    Använd en befintlig CLI-inloggning eller konfigurera en API-anslutning och kontrollera sedan den valda modellen.Use an existing CLI login or configure an API connection, then verify the selected model.

    Codex eller Claude på den här datorn

    Startkortet och personpanelen erbjuder ett lokalt anslutningskort för Codex och Claude. Installera och logga in i motsvarande CLI på datorn som kör spelet. Uppdatera statusen och välj sedan en tillgänglig, autentiserad leverantör som inte behöver uppdateras. Spelet startar CLI-förfrågan med denna befintliga inloggning.

    Lämna det valfria modellnamnet tomt för kontots förval eller ange en modell som kontot har tillgång till. Om kortet visar en för gammal Codex är uppdateringskommandot npm install -g @openai/codex@latest. Uppdatera statusen efteråt. Denna anslutning fungerar bara genom värddatorns lokala loopback-anslutning.

    Codex or Claude on this computer

    The start card and character panel offer a local connection card for Codex and Claude. Install and sign in to the corresponding CLI on the computer running the game. Refresh its status, then select an available, authenticated provider that does not require an update. The game starts the CLI request using that existing login.

    Leave the optional model name empty to use the account's default, or enter a model available to that account. If the card reports an outdated Codex, its displayed update command is npm install -g @openai/codex@latest; refresh status afterwards. This bridge is available only from the host computer's loopback connection.

    API-anslutningar och leverantörstyper

    Öppna de avancerade modellinställningarna för att använda en API-leverantör. Den behållna leverantörslistan omfattar Gemini, OpenAI, Anthropic, OpenAI-kompatibel och Anthropic-kompatibel utöver de två lokala CLI-transporterna. En inbyggd API-anslutning behöver en nyckel. En kompatibel anslutning behöver serverns URL och kan också kräva en nyckel. Spara anslutningen en gång och välj sedan en modellpost som använder den.

    Nycklar och modellinställningar lagras i den här klientprofilens lokala lagring. Utgå inte från att en nyckel i en webbläsare finns i en annan. Tillgänglighet, debitering och kontogränser bestäms av leverantören. Ett modellnamn i spelets förval bevisar inte att ditt konto kan använda det.

    API connections and provider types

    Open the advanced model connection settings to use an API provider. The retained provider list includes Gemini, OpenAI, Anthropic, OpenAI Compatible and Anthropic Compatible, alongside the two local CLI transports. A native API connection needs a key; a compatible endpoint needs its server URL and may also require a key. Store each connection once, then choose a model entry that uses it.

    Keys and model settings are stored in this client profile's local storage. Do not assume a key configured in one browser is present in another. Availability, billing and account limits come from the provider; a model name in the game's defaults is not proof that your account can use it.

    Lokala och kompatibla modellservrar

    För en lokal OpenAI-kompatibel server anger du dess /v1-basadress och den modell den serverar. Den konfigurerade lokala standardadressen är http://localhost:11434/v1. På en annan enhet ersätter du localhost med modelldatorns adress. Spelet kan hitta modeller från en kompatibel server när inget modellnamn anges.

    Förfrågningar går normalt direkt till leverantören. En lokalt körd sida kan använda det lokala reläet när en webbläsarförfrågan blockeras och kommer ihåg den vägen för den berörda servern. Androids adapter använder inbyggd HTTP direkt för lokala servrar och buffrar svaret. Ett statiskt webbbygge har inget lokalt Node-relä. Kontrollera serveradressen, policyn för webbläsaråtkomst och det laddade kontextfönstret om anslutningen misslyckas.

    Local and compatible model servers

    For an OpenAI-compatible local server, enter its /v1 base URL and the model it serves. The configured local default is http://localhost:11434/v1. On another device, replace localhost with the model computer's address. The game can discover models from a compatible server when no model is specified.

    Requests normally go directly to the provider. A local page can use its relay when a browser request is blocked, and remembers that route for the affected server. The Android adapter goes directly through native HTTP for local servers and buffers the reply. A static web build has no local Node relay. Check the server’s address, browser access policy and loaded context window when setup fails.

    Anslutningar och reservlistan

    En anslutning innehåller leverantör, adress och autentiseringsuppgifter. En modellpost hänvisar till en anslutning. Lägg till eller ordna om poster i modellinställningarna för att styra försöksordningen. Om en anslutning tas bort försvinner även posterna som använder den. Att tömma modellistan behåller anslutningarna men lämnar ingen modell som kan svara.

    Reservhanteringen börjar normalt överst eller med den post som tilldelats den aktuella uppgiften. Den skiljer på förbrukad kvot, oanvändbar konfiguration, upptagen leverantör och kortvarig anropsbegränsning. Statusvisningen och återställningsreglaget hjälper dig rätta den berörda posten. Vid anropsbegränsning kan policyn välja nästa post eller vänta. Detta är reservhantering efter ett fel, inte en rotation som fördelar förfrågningar mellan konton.

    Connections and the fallback list

    A connection holds the provider, endpoint and credentials. A model entry references a connection. Add or reorder entries in the Models settings to set the order of attempts; removing a connection also removes entries that use it. Clearing the model list keeps the connections but leaves no model to answer.

    The fallback runner normally starts at the top, or at the entry assigned to the current task. It distinguishes an exhausted allowance, an unusable configuration, a busy provider and a short rate limit. The status display and reset control help you fix the affected entry. The rate-limit policy can try the next entry or wait. This is fallback after a failure, not a rotation that spreads requests across accounts.

    Vad en modell får ändra

    Modellen tolkar fritexthandlingar och skriver berättelsen. Personmotorn validerar och avgör utfallen. Du bekräftar fortfarande din egen föreslagna handling innan den utförs. Ett misslyckat modellår godtas inte tyst som en färdig persontur. Använd menyn när tolkningen misslyckas och läs felsökningen vid anslutnings- eller valideringsfel.

    What a model may change

    The model interprets free-text actions and writes narration; the character engine validates and resolves outcomes. You still confirm your own proposed action before it runs. A failed model year is not silently accepted as a completed character turn. Use the menu when interpretation fails and read troubleshooting for connection or validation errors.
