    Starta från projektets källkod

    Den dokumenterade vägen för Attainder använder Node.js 24, npm och en installerad, inloggad Codex CLI eller Claude Code. Kör följande i en terminal:

    git clone https://github.com/sp1e/Attainder.git
cd Attainder
npm ci
node scripts/fetch-map-assets.mjs --ensure
npm run build
node scripts/launch-dynasties.mjs

    På Windows kan du efter den första byggningen dubbelklicka på Start-Attainder.cmd. Startaren öppnar http://127.0.0.1:4167. Anslut en modell och välj sedan en historisk start och om du vill följa riket eller familjen.

    Start from the project checkout

    The documented Attainder route uses Node.js 24, npm, and an installed, signed-in Codex CLI or Claude Code. In a terminal, run:

    git clone https://github.com/sp1e/Attainder.git
cd Attainder
npm ci
node scripts/fetch-map-assets.mjs --ensure
npm run build
node scripts/launch-dynasties.mjs

    On Windows, after the first build you can double-click Start-Attainder.cmd. The launcher opens http://127.0.0.1:4167. Connect a model, then choose a historical start and whether to follow the realm or the family.

    Kartfiler och ditt bibliotek

    Hämta kartfilerna före byggningen: byggningen kopierar dem till dist/. Den dokumenterade hämtningen är cirka 290 MB. Saknade filer gör att kartförfrågningar misslyckas. Du kan köra hämtningskommandot igen när filer saknas eller är inaktuella.

    Nya utcheckningar lagrar kampanjer i play-data/ och startloggar i reports/launcher/. ATTAINDER_DATA_HOME väljer en annan dataplats. Det äldre namnet TIDES_DATA_HOME fungerar också. Säkerhetskopiera biblioteket och exportera viktiga kampanjer innan du ersätter en installation.

    Map files and your library

    Fetch the map files before building: the build copies them into dist/. The documented download is about 290 MB; missing files lead to failed map requests. The fetch command can be run again when files are missing or outdated.

    Fresh checkouts keep campaigns in play-data/ and launcher logs in reports/launcher/. ATTAINDER_DATA_HOME selects another data home; the older TIDES_DATA_HOME name is still accepted. Back up your library and export important campaigns before replacing an installation.

    Skrivbords-, webb- och Androidbyggen

    Använd källkodsstarten ovan för den dokumenterade installationen. Om du väljer ett skrivbords-, webb- eller Androidpaket kontrollerar du vilken Attainder-version utgivaren har tagit med.

    En statisk webbplats kan inte starta den lokala CLI-anslutningen på din dator. Inställningarna har konfiguration för API-leverantörer. Läs om modellanslutning, mobilens begränsningar och egen server för de tillgängliga anslutningarna.

    Desktop, web and Android builds

    Use the source launch above for the documented setup. If you choose a desktop, web or Android package, check which Attainder version its publisher includes.

    A static website cannot start the local CLI bridge on your computer. API-provider configuration is available through settings. Read model setup, mobile limitations and self-hosting for the available connections.

    Uppdateringar och erkännanden

    För en källkodsutcheckning installerar du uppdaterade beroenden, hämtar aktuella kartfiler och bygger om innan du startar den nya koden. Den ärvda automatiska uppdateraren använder utgivningsflöden uppströms. Den är ingen garanti för Attainder-uppdateringar. Behåll en säkerhetskopia när du byter version.

    Updates and attribution

    For a source checkout, install the updated dependencies, refresh map assets and rebuild before launching the new code. The inherited automatic updater targets upstream release feeds; it is not an Attainder update guarantee. Keep a backup before changing versions.
