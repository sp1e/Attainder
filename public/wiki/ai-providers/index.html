    Vad modellen måste lämna

    Rollfigurssamtal ber modellen om strukturerade handlingsdata och berättande text. Spelet kontrollerar dessa data innan det godkänner en handling. Börja med att kontrollera att den valda modellen följer formatet och att svaret stämmer med scenen.

    De lokala anslutningarna till Codex och Claude använder de installerade programmen och deras befintliga inloggningar. API-anslutningar använder de inloggningsuppgifter och den adress du anger. Läs om att ansluta en modell.

    What a model must return

    Character interactions ask the model for structured action data as well as narrative text. The game validates that data before accepting an action. Start by checking that the selected model follows the requested format and keeps its answer consistent with the scene.

    The local Codex and Claude connections use the installed programs and their existing logins. API connections use the credentials and endpoint you configure. See connecting a model.

    Standardmodeller och val per uppgift

    Geminis förval är gemini-3.5-flash-lite, följt av gemini-3.1-flash-lite. OpenAI har gpt-6-luna som förval och Anthropic har claude-haiku-4-5. En kompatibel server kan lämna en modell genom modellupptäckt när modellfältet är tomt. Ett tomt modellfält för den lokala CLI-anslutningen använder kontots standardmodell.

    Detta är konfigurerade förval. Tillgängligheten beror på leverantören och ditt konto. Ett val per uppgift kan välja en post innan reservlistan prövas. Kontrollera den faktiskt använda posten i diagnostiken om du undersöker en ändrad skrivstil.

    Defaults and task choices

    The configured Gemini defaults are gemini-3.5-flash-lite followed by gemini-3.1-flash-lite. OpenAI defaults to gpt-6-luna; Anthropic defaults to claude-haiku-4-5. A compatible endpoint can discover a model when its model field is blank. Leaving the local CLI model blank uses the account default.

    These are configuration defaults. Availability depends on the provider and your account. A per-task choice can select an entry before the fallback list is tried. Check the entry actually used in diagnostics when investigating a different writing style.

    Anrop, kostnad och kontext

    En interaktion kan kräva tolkning och ett separat berättaranrop. Omförsök och reservposter kan ge fler anrop. Kontrollera användningsvillkor och avgifter hos din leverantör. Den lokala CLI-anslutningen använder kontot som är inloggat i programmet.

    Ladda en tillräckligt stor kontext i en modellserver på din dator eller ditt nätverk. Modellposten har en inställning för kontextfönster och möjlighet att rensa en inlärd gräns. En lokal server kan laddas om med ett annat fönster. Kontrollera därför dess aktuella konfiguration när en förfrågan är för stor.

    Requests, cost and context

    One interaction can require interpretation and a separate narrative request. Retries and fallback entries can add calls. Check your provider account for its usage terms and charges; the local CLI uses the account signed into that program.

    For a model server on your machine or network, load a context window large enough for the request. The model entry exposes a context-window setting and a way to clear a learned limit. A local server can be reloaded with a different window, so verify its current configuration when a request is too large.

    Avancerade reglage

    En anslutning kan ange egna anropsparametrar. OpenAI-kompatibla anslutningar erbjuder också Strikt verktygsschema. En modellpost kan ersätta de egna parametrarna och välja hur strukturerade svar begärs. Modellresonemang finns där leverantören stöder det. Ändra en inställning i taget och granska anropet när du undersöker formatfel.

    Reglagen påverkar modellförfrågan. Spelet kontrollerar fortfarande den föreslagna handlingen innan den genomförs. Om inget anrop når modellen kontrollerar du först inloggning, inloggningsuppgifter och serveradress.

    Expert controls

    A connection can set custom request parameters. OpenAI-compatible connections also offer Strict tool schema. A model entry can override custom parameters and select how structured answers are requested. Model reasoning is available where the provider supports it. Change one setting at a time and inspect the resulting request when diagnosing format failures.

    These controls affect the model request. The game still validates the proposed action before committing it. If no request reaches the model, check login, credentials and endpoint first.

    Granska ett anrop

    Öppna AI-felsökningskonsolen i verktygsmenyn för att granska förfrågningar, svar, modelluppgifter, tokenantal, svarstid och valideringsresultat samt exportera JSON eller CSV. När beständig telemetriinspelning är på behålls de senaste 200 posterna. Detaljerad diagnostikloggning kan innehålla hela förfrågningar och svar. Läs exporten innan du delar den.

    Räknaren för lokala modellanrop uppdateras av CLI-transporten. Betrakta den som en räknare för lokala CLI-anrop och inte som en fullständig faktura för alla API-anslutningar. Läs felsökningen vid anslutningsfel.

    Inspect a request

    Open AI debug console from the tools menu to inspect prompts, answers, model details, token counts, latency and validation results, and export JSON or CSV. With persistent telemetry recording enabled, the store retains the latest 200 records. Detailed diagnostic logging can include full prompts and replies; read the export before sharing it.

    The local model-call counter is updated by the CLI transport. Treat it as a local CLI counter rather than a complete bill for every API connection. See troubleshooting for connection failures.
