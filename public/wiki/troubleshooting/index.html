    Kartan är tom

    Vid en källkodsinstallation kör du node scripts/fetch-map-assets.mjs --ensure före npm run build och startar sedan igen. Bygget kopierar kartresurser till sitt resultat. Om en importerad kampanj anger att kartan saknas återställer du scenariots matchande geografi. Samma scenarioidentifierare räcker inte. Läs om installation och kartåterställning.

    En WebGL-varning betyder att renderaren saknar en grafikkontext. Den kontrollerar igen i ungefär 30 sekunder och laddar om sidan om WebGL blir tillgängligt. Kontrollera hårdvaruacceleration och grafikdrivrutiner om problemet kvarstår. Minska terräng- eller jordglobseffekter eller dölj landsetiketter i kartinställningarna om visningen är långsam.

    The map is blank

    For a source installation, run node scripts/fetch-map-assets.mjs --ensure before npm run build, then launch again. The build copies map assets into its output. If an imported campaign reports a missing map, restore the matching scenario geography; a matching scenario identifier alone is insufficient. See installation and map restoration.

    A WebGL warning means the renderer lacks a graphics context. It checks again for roughly 30 seconds and reloads if WebGL returns. If it persists, check hardware acceleration and graphics drivers. Reduce terrain, globe effects or country labels through map settings when drawing is slow.

    Modellen svarar inte

    För lokal Codex eller Claude kontrollerar du att CLI-programmet är installerat och inloggat på värddatorn. Uppdatera anslutningskortet och läs statusen. Den lokala anslutningen accepterar bara klienter på den egna datorn. En annan enhet kan inte använda den genom LAN-delning.

    För en API-anslutning kontrollerar du nyckel, modellnamn och basadress. Kompatibla anslutningar behöver vanligen API-basen, till exempel /v1, och inte en webbplatsadress. En lokal modellserver på en annan dator behöver den datorns adress. Webbläsarens åtkomstregler och tillgång till inbyggd eller lokal transport spelar roll. Följ modellanslutningen.

    The model does not answer

    For local Codex or Claude, check that the CLI is installed and logged in on the host computer, refresh the connection card and read its status. The local bridge accepts loopback clients only; another device cannot use it through LAN sharing.

    For an API connection, check the key, model name and base endpoint. Compatible endpoints usually need their API base, such as /v1, rather than a website URL. A local model server on another computer needs that computer’s address. Browser access rules and native/local transport availability matter; follow model setup.

    Svaret avvisas

    Läs det angivna valideringsfelet och granska förfrågan i AI-felsökningskonsolen. Rollfigurshandlingar behöver strukturerade data och berättande text. En flytande text kan ändå bryta mot det schema som krävs. Strikt verktygsschema och reglagen för strukturerade svar i en OpenAI-kompatibel anslutning kan påverka formatet. Kontrollera den laddade modellens kontextfönster om förfrågan är för stor.

    Historiska rollfigursår använder ett strikt flöde utan reservhopp med förskrivna händelser. En misslyckad generering avvisas i stället för att godtas som en färdig rollfigurstur. Rätta modellanslutningen eller svarsformatet innan du försöker igen.

    The response is rejected

    Read the reported validation reason and inspect the request in the AI debug console. Character actions need structured data as well as narration; a fluent paragraph can still fail the required schema. An OpenAI-compatible connection’s Strict tool schema and structured-answer controls can affect formatting. Check the loaded model’s context window if the request is too large.

    Historical character years use a strict path with no canned jump fallback. A failed generation is rejected instead of being accepted as a completed character turn. Fix the model connection or response-format problem before retrying.

    Omförsök, pausat arbete och gränser

    När ett misslyckat rådgivar- eller diplomatisvar erbjuder ett omförsök kan den sparade frågan eller meddelandet användas igen. Det senaste felet är det som har ett omförsöksreglage. Om tidslinjen håller kvar ett misslyckat segment eller en uppdatering av projekttavlan använder du dess särskilda val för omförsök eller borttagning. Läs meddelandet innan du startar ett helt nytt tidshopp.

    Modellposter skiljer på förbrukad kvot, oanvändbar konfiguration, tillfällig belastning och korta anropsbegränsningar. En reservmodell kan svara när en annan post inte kan. En annan post kan också ändra skrivstilen. Läs postens aktuella status och reservinställningarna. Spelets anropsräknare ersätter inte leverantörskontots användningsuppgifter.

    Retries, held work and limits

    Where a failed advisor or diplomatic reply offers Retry, it can reuse the saved question or message. The newest error is the one with a retry action. If the timeline holds a failed segment or project-board update, use its specific retry or discard choice; inspect the message before starting a whole new skip.

    Model entries distinguish exhausted allowance, unusable configuration, temporary load and short rate limits. A backup can answer when another entry cannot; a different entry can also change the writing style. Read the actual entry status and fallback settings. The game’s request counters do not replace your provider account’s usage records.

    Saknade spel och gemenskapsfiler

    Kontrollera den webbläsarprofil, adress och lokala datarot som du använde när du spelade. Källkodsstarten väljer en datarot och använder dess play-data-mapp. Ren webbläsardrift använder webbläsarlagring. Exportera en kampanj innan du rensar webbplatsdata eller byter installation. Läs om sparfiler.

    Gemenskapshubben listar granskade filer från sitt index. Om indexet inte kan läsas eller filen inte är granskad misslyckas importen i stället för att hämta en ogranskad bilaga. Indexet cachelagras i fem minuter. En import kan också misslyckas för att scenariot inte är förberett för det historiska spelet. Läs hubbens guide. Om världen har blivit motsägelsefull granskar du rätt världsverktyg och behåller en kopia innan du ändrar den.

    Missing games and community files

    Check the browser profile, address and local data home you used when playing. The source launcher selects a data home and uses its play-data directory. Browser-only games use browser storage. Export a campaign before clearing site data or replacing an installation. See saves.

    The Community Hub lists checked files from its index. If the index cannot be read, or a file is not checked, importing fails rather than fetching an unchecked attachment. The index is cached for five minutes. An import can also fail because the scenario is not prepared for this historical game. See the hub guide. For an incoherent world, inspect the relevant world tools and keep a copy before changing it.

    Rapportera ett fel som går att återskapa

    Öppna Avancerad → Diagnostik, slå på Detaljerad loggning, återskapa felet och spara loggen. Läs den innan du delar den. Detaljerade poster kan innehålla hela samtal och modellutbyten. Ange plattform, Attainder-version, vald leverantör och modell, arbetssteg och det exakta felet.

    Vid problem med källkodsstarten granskar du serverns utdata- och felloggar under reports/launcher i den valda dataroten. För ett paketerat bygge anger du också vilket paket och vilken version som misslyckades. Använd Attainders ärendehantering för det här projektet.

    Report a reproducible failure

    Open Advanced → Diagnostics, turn on Detailed logging, reproduce the failure and save the log. Read it before sharing: detailed records can contain full conversations and model exchanges. Include your platform, the Attainder version, the selected provider/model, the steps and the exact error.

    For a source-launch problem, inspect the server output and error logs under reports/launcher in the selected data home. For a packaged build, also record which package/version failed. Use the Attainder issue tracker for this project.
