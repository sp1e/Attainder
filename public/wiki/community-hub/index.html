    Bläddra i gemenskapskatalogen

    Bibliotekets gemenskapsflik läser den gemensamma scenariohubben. Den visar fästa inlägg när sådana finns, följt av hyllor för installationer, gillanden och nyheter. Sök för att hitta ett inlägg och öppna dess detaljvy för att läsa beskrivningen innan du importerar.

    Katalogen ligger utanför ditt lokala kampanjbibliotek. För en start som stöds använder du de förberedda historiska valen under starta ett spel. Även ett scenario i en extern katalog måste klara det här spelets förberedelsekontroller.

    Browse the community catalogue

    The library’s Community tab reads the shared scenario hub. It shows pinned posts when there are any, followed by installed, liked and recent shelves. Search helps find a post; open its detail view to read the description before importing.

    The catalogue is external to your local campaign library. For a supported start, use the prepared historical choices in starting a game. A scenario offered by a remote catalogue still has to pass this game’s preparation checks.

    Importera och uppdatera en kopia

    Importen hämtar hubbens granskade scenariofil och försöker installera den i ditt bibliotek. Om förberedelse- eller kartkontrollen misslyckas läser du felet i stället för att anta att katalogens version är kompatibel. Använd en förberedd historisk start medan du löser avvikelsen.

    En uppdatering ersätter den hämtade scenariokopian. Klona den först om du har redigerat den. Ersättningsvarningen säger att dina ändringar kommer att försvinna. Behåll en export när befintliga kampanjer är beroende av scenariots karta. Läs om sparfiler och matchande kartor.

    Import and update a copy

    Import downloads the hub’s checked scenario file and tries to install it into your library. If it fails preparation or map validation, read the error rather than assuming the catalogue’s version is compatible. Keep using a prepared historical start while resolving the mismatch.

    An update replaces the downloaded scenario copy. If you edited it, clone it first; the replacement warning says that your changes will be lost. Keep an export when existing campaigns depend on the scenario’s map. See saves and matching maps.

    Publicera eller föreslå ändringar

    Publicering exporterar ditt valda scenario och öppnar ett förifyllt GitHub-inlägg. Bifoga det hämtade paketet och en eventuell separat hämtad omslagsbild, granska formuläret och skicka in det själv. Förberedelsen av filerna publicerar inte inlägget automatiskt.

    Ett länkat scenario kan också förbereda en förslagsfil till författaren. Förslagsreglagen sparar filen och kan öppna inlägget. Granska det du skickar innan du bifogar filen. Arbeta på en redigeringskopia och behåll en export av din egen version.

    Publish or suggest changes

    Publishing exports your chosen scenario and opens a prefilled GitHub post. Attach the downloaded bundle and any separately downloaded cover image, review the form and submit it yourself. Preparing these files does not publish the post automatically.

    A linked scenario can also prepare a suggestion file for its author. The suggestion controls save the file and optionally open the post; review what you are sending before attaching it. Work on an editor copy and keep an export of your own version.

    Granskade filer och delningsvillkor

    Klienten använder hubbens index för att hitta granskade utgivningsfiler. Den hämtar inte en ogranskad inläggsbilaga som reserv om filen saknas i indexet. Indexets cache gäller i fem minuter, så en ny utgåva kan dröja innan den syns. Även hämtningar av baskartor och flaggor använder hubbens mekanism för granskade filer där de erbjuds.

    Programmets delningsmeddelande anger att scenarier som skapats i Open Historia och publiceras eller delas släpps under Creative Commons Attribution 4.0 International (CC BY 4.0). Förslag följer dessa delningsvillkor. Paketen innehåller en licenspost och ZIP-filer innehåller LICENSE.txt. Material som författaren inte äger och separat refererade resurser behåller sina egna rättigheter och villkor. Bevara Open Historias tillskrivning och källkodens meddelanden om AGPL-3.0-or-later.

    Checked files and sharing terms

    The client uses the hub’s index to find checked release files. It does not fall back to an unchecked post attachment when a file is missing from that index. The index cache lasts five minutes, so a new release may take time to appear. Basemap and flag downloads also use the hub’s checked-file mechanism where offered.

    The application’s sharing notice releases scenarios made in Open Historia and posted or shared under Creative Commons Attribution 4.0 International (CC BY 4.0). Suggestions follow those sharing terms. Bundles carry a licence record and ZIP files carry LICENSE.txt. Material the author does not own and separately referenced assets keep their own rights and terms. Preserve Open Historia attribution and the source code’s AGPL-3.0-or-later notices.
