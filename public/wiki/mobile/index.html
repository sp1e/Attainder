    Open Historia / Guide / Phones, tablets and Android builds

    Telefoner, surfplattor och AndroidbyggenPhones, tablets and Android builds

    Använd ett mobilbygge eller öppna din delade lokala kampanj från en annan enhet.Use a mobile build or open your shared local campaign from another device.

    Vad projektet innehåller

    Kontrollera vilken Attainder-version utgivaren har tagit med i ett mobilpaket. Följ installationen för starten på en lokal dator.

    Androidprojektet kräver SDK 23 eller senare, motsvarande Android 6.0. Byggskripten förbereder lokala webb- och kartresurser. Behåll en kampanjexport utanför appens lagring innan du byter eller avinstallerar appen.

    What the repository provides

    For a mobile package, check which Attainder version its publisher includes. Follow installation for the local computer setup.

    The Android project requires SDK 23 or later (Android 6.0). Its build scripts prepare local web and map assets. Keep a campaign export outside app storage before replacing or uninstalling the app.

    Välj en transport som enheten når

    En telefon kan inte använda värddatorns CLI-anslutning till Codex eller Claude. Den vägen är begränsad till den egna datorn. En webbläsare eller det behållna Androidbygget kan i stället använda den konfigurerade API-transporten. För en modellserver på en annan dator använder du den datorns nätverksadress, inte telefonens localhost. Webbläsarförfrågningar beror på modellserverns CORS-policy. Androids inbyggda HTTP-adapter lämnar hela svaret i stället för att strömma det.

    Om telefonen ska vara en annan skärm för värddatorns kampanj läser du om nätverksdrift. Den når samma bibliotek. Det skapar ingen separat kampanj eller flerspelarlobby.

    Choose a transport that the device can reach

    A phone cannot use the host computer's Codex/Claude CLI bridge: that route is restricted to loopback. A browser or retained Android build can instead use the configured API transport. For a model server on another computer, use that computer's network address, not the phone's localhost. Browser requests depend on the model server's CORS policy; the Android native HTTP adapter returns a complete response rather than streaming it.

    For a phone acting as another screen for the host's campaign, read network hosting. It accesses the same library; it does not create a second independent campaign or a multiplayer lobby.

    Exporter och bakgrundsbeteende

    I Androidskalet skrivs exporter till Download/Open Historia när filsystemstillägget kan göra det. Om skrivningen misslyckas sparar koden en cachekopia och erbjuder delningsrutan när den finns. Kontrollera meddelandet om sparad fil och behåll en kopia utanför appens lagring innan du avinstallerar en app.

    Bakgrundspausen väntar på att genereringen ska avslutas innan den begär viloläge. En omstart av den inbyggda renderaren kan registreras i diagnostiken. Ingen av mekanismerna ersätter en säkerhetskopia av kampanjen.

    Exports and background behaviour

    In the Android shell, exports are written to Download/Open Historia when the filesystem plugin can do so. If writing there fails, the code saves a cache copy and offers the share sheet when available. Check the saved-file notice and keep a copy outside app storage before uninstalling an app.

    The background-pause hook waits for generation to finish before requesting an idle pause. A native renderer restart can be recorded in diagnostics. Neither mechanism replaces a campaign backup.

    Använda en liten skärm

    Kartan har dragpanorering och avstängda gester för lutning. Justera karteffekter i inställningarna om visningen är långsam.

    En webbläsare på en annan enhet kan nå din uttryckligen delade lokala server, med dess begränsningar för modeller och nätverk. Läs om egen server.

    Using a small screen

    The map enables drag panning and disables pitch gestures. Adjust map effects in settings if the display is slow.

    A browser on another device can reach your explicitly shared local server, subject to its model and network limitations. See self-hosting.
