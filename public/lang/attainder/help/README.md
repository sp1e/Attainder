# Attainder help text

This catalog supplies 32 adapted guide pages in Swedish and English, plus shared navigation and shell text. The 398 paired fields have received bilingual and source review. The source snapshot is recorded in `manifest.json`; its page evidence was also checked against the revision named by `verifiedAgainstRevision`.

Read `manifest.json` for page files, canonical routes, section counts and SHA-256 file identities, computed over the LF bytes that Git stores. A page uses `attainder-help-page-v1`: `title`, `nav`, `description`, and each section's `title` and Markdown `body` contain `sv` and `en`. Section IDs and routes remain the same in both languages. Evidence references identify the implementation at the pinned source revision; upstream file hashes identify the original help used for adaptation. `topicDispositions`, where present, explain which original topics were retained, changed or excluded.

`navigation.json` supplies the reading order and six paired section labels. Page navigation labels come from the referenced page. `shell.json` supplies shared controls, accessible labels, the current-guide note and the complete upstream legal notice.

The content describes the current historical game. It distinguishes dynasty controls from general country tools that are available only in campaigns without a character system. Older upstream beta features are not treated as present merely because their help pages exist.

`scripts/build-wiki.mjs` renders this catalog into `public/wiki/`: every page in Swedish and English in one file, with localized search indexes and the language chosen from the page's own switch or the game's Options; [docs/wiki.md](../../../../docs/wiki.md) describes how. After any edit to a page file, `navigation.json` or `shell.json`, run `node scripts/build-wiki.mjs` and commit the regenerated `public/wiki/` and `public/sitemap.xml` in the same PR; `src/runtime/wikiHelp.test.js` fails when the committed pages differ from a fresh build. After editing a file listed in `manifest.json`, recompute its `sha256` over the LF bytes. Preserve original upstream help separately, and retain Open Historia attribution and AGPL notices, including the original subject of the legal notice in `shell.json`.
